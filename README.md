# **To-Do List — Regan Patel, MSCIT**

**Simple, modern, and responsive To-Do list web app** built with **HTML**, **CSS** and **JavaScript**.  
Stores tasks in the browser using **localStorage**, supports adding, deleting, marking complete, and filtering tasks (All / Active / Completed).

## **🌟 Project Overview**
A lightweight single-page To-Do application that is:
- Easy to read and customize
- Fully client-side (no backend)
- Responsive and keyboard-friendly
- Great for learning DOM manipulation and storing data with `localStorage`

## **✨ Features**
- Add new tasks (press **Enter** or click **Add**)
- Mark tasks as **completed**
- Delete individual tasks
- Filter tasks: **All**, **Active**, **Completed**
- **Clear completed** tasks button
- Tasks persist between sessions using `localStorage`
- Accessible (focus on input on load) and responsive UI
